# Telecom-Customer-Churn-Analysis-Python-MySQL-Power-BI

# 📊 Customer Churn Analysis Dashboard

A complete **Customer Churn Analysis** project that demonstrates the end-to-end data analytics workflow. This project covers **data cleaning, exploratory data analysis (EDA), SQL-based business insights, and an interactive Power BI dashboard** to help understand customer churn patterns.

---

## 📌 Project Overview

Customer churn is one of the biggest challenges faced by subscription-based businesses. The goal of this project is to identify the factors influencing customer churn and provide actionable insights through data analysis and visualization.

This project follows the complete analytics pipeline:

- Data Collection
- Data Cleaning & Preprocessing
- Exploratory Data Analysis (EDA)
- SQL Business Insights
- Interactive Power BI Dashboard

# 📊 Key Insights

- Month-to-Month contract customers have the highest churn rate.
- Customers using Fiber Optic internet churn more frequently.
- Electronic Check users show higher churn.
- Customers with shorter tenure are more likely to leave.
- Customers without Tech Support and Online Security are more likely to churn.
